# TeleChat

A small SwiftUI chat prototype for Mac, iPhone, and iPad. It opens with a sample conversation and lets you add messages to the current thread.

## Run locally

1. Open `TeleChat.xcodeproj` in Xcode 27 or later.
2. Select **My Mac** (macOS 26 or later) or an iPhone/iPad simulator running iOS 27 or later.
3. Press **⌘R**.

No account, server, or dependencies are required. Messages stay in the current session and reset when the app relaunches. A successful build and launch have not yet been verified.
